# Employee Management SQL Database

## Overview

A relational employee management database built using MySQL
to practice database design and real-world SQL querying.

## Database Structure

- Employees
- Managers
- Departments
- Employee-Manager relationships

## SQL Concepts

- CRUD Operations
- Filtering & Sorting
- Aggregate Functions
- String & Date Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- GROUP BY
- HAVING
- Subqueries
- CTEs
- Views
- Indexes
- Transactions
- Primary & Foreign Keys
- Constraints

## Key Features

- Relational database design
- Foreign key relationships
- ON DELETE behavior
- Employee-manager data analysis
- Business-oriented SQL queries
